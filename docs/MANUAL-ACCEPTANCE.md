## iPhone Safari 与主屏幕

使用合成测试记录，先保存 v3 备份；不要清理已有真实记录。Safari 访问正式 Pages，等待“离线资源已准备完成”，输入笔记、改状态、作答；“已保存本机”后关闭重开核对。下载一张原卷到“文件”。开启飞行模式，重载并核对题目、不同公式字体和个人记录；未下载图片可失败，应用壳应可用。

分享 → 添加到主屏幕，核对图标与启动路径。主屏幕可能使用独立站点存储，先备份并用 v3 导入，不能假设与 Safari 共用数据。安装后离线关闭重开。发布新版本时，在输入笔记期间触发更新，必须先完成本机事务，不能自动刷新或丢草稿；旧缓存仍可用。

## 双设备

默认仅本地模式：两设备分别从同一 v3 备份开始，离线编辑相同/不同字段、不同笔记并作答。各自导出 v3，再交换导入；两端显示应收敛，笔记冲突保留，答题按ID去重。重复导入不增加事件；明确解决冲突后另导出交换，祖先版本仍在完整备份。不要将本地双标签测试描述成双设备云同步。

如接入 D：真实测试项目中先验收 RLS/RPC，再分别登录同一测试账号；备份及再次确认前不发送匿名记录。测试断网、关闭、前台恢复、丢响应、Realtime断开、分页、退出和切换测试账号。检查账号B看不到A数据，A的未发送项退出后仍保留，不向B发送。
